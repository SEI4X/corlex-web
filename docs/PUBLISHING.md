# Release process

This source candidate is not a registry release. An owner reviews and merges the public PR only after build/security checks pass. Before a draft release, record the public commit, source manifest, dependency/SBOM/license review, npm-pack contents and SHA-256 checksums. Publish only the reviewed archive; create no npm identity or token automatically. Version 0.1.0 remains unreleased until owner acceptance. Repository ownership can be transferred separately from npm package ownership.
