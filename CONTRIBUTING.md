# Contributing

This repository currently contains release preparation documents. Source code,
build instructions, and public CI will be added in a reviewed source release.

Use GitHub issues for ordinary bug reports and feature requests, and submit
changes through public pull requests. Describe the change and the checks you
actually ran. Do not claim build or test results that were not run.

Contributions must work without access to private services or repository
secrets. Public CI uses GitHub-hosted runners. Never attach a personal or
self-hosted runner to execute untrusted public pull requests.

Keep credentials and personal customer data out of examples, logs, and commits.
Report security issues privately using [SECURITY.md](SECURITY.md).
